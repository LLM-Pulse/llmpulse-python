# CitationMatchMode

How citations are attributed: domain (the domain and its subdomains), host (that exact host) or path_prefix (URLs under citation_match_path)

## Enum

* `DOMAIN` (value: `'domain'`)

* `HOST` (value: `'host'`)

* `PATH_PREFIX` (value: `'path_prefix'`)
